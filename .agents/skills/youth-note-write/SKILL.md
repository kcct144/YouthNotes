# 学科笔记写作

先读仓库根目录 `AGENTS.md` 与[笔记写法](../../../docs/guide/writing.md)，新页面参考[模板](../../../templates/note.md)。技能随仓库提供，所有路径以仓库根目录为基准执行。

先查找已有主题，优先完善同一页。依据用户给出的学习目标、学段、教材与材料写作；缺少教材版本时不虚构版本和年级，确实影响内容时再询问。

以理解为中心：概念解释准确且有条件，适当使用直观例子；考点归纳识别线索、适用方法、完整例题和检验；坑点给错因、反例与自查。按内容需要选择三类，不为补齐结构重复正文。

新页放入 `docs/notes/<学科>/junior/` 或 `senior/`，跨学段主题放 `shared/`；通用学习方法放 `docs/methods/`。使用已有提示块和 Markdown，关闭的自动 frontmatter 不要重新启用。

例题独立计算，明确原创或真实出处。教材页码、考试频率、真题年份、实验数据和引用必须有依据；不确定内容标为待核对，不能当作已确认结论。

贡献者与修改记录使用文章顶部的 `noteContributors`、`noteChanges`，参考[填写教程](../../../docs/guide/contributions.md)。只据用户提供或已确认的真实资料填写；学生贡献与维护者代录分开，录入人放 `recordedBy`，不从 Git 或 AI 生成过程推断署名。没有资料时保留空列表。移动文章保留记录，拆分或合并时按实际保留的内容整理。

公式或图表按需查阅[公式与图表](../../../docs/guide/math-and-charts.md)。完成后修复入口链接，运行 `pnpm docs:check`、`pnpm docs:build`，说明需人工学科审校的部分。提交、推送与部署遵循用户当次授权。
