# 理科公式与图表

读取根目录 `AGENTS.md`、[公式与图表教程](../../../docs/guide/math-and-charts.md)及目标页面。先判断视觉表达要帮助学生理解什么，正文已能讲清的小事实不必增加图表。

复用当前配置：KaTeX 用 `$...$`、`$$`；化学式用 `\ce{...}`；关系与流程用 `mermaid`；函数、实验与统计图用 JSON 格式的 `echarts` 代码块。不为普通公式引入组件或启用脚本执行。

公式写明变量、单位与条件；化学方程式核对配平与所需条件。数值型函数图用数值坐标，标出取值范围；采样点不能被描述成未显示的完整图像。数据来自明确来源或可复算表达式，模拟数据注明模拟。

正文、题解与图表使用同一组可核算数据。关键图表配文字解释或数据表；颜色之外使用标签，窄屏与深色模式下应能阅读。

标题分类与层级遵循[笔记写法](../../../docs/guide/writing.md#标题分类与层级)，不要另设配色或固定内容分块。需要交互练习时，只按[交互练习写法](../../../docs/guide/writing.md#按需添加交互练习)使用已有组件，不在此维护第二套属性、插槽或评分规则。

参照[一次函数示范](../../../docs/notes/math/junior/linear-function.md)实现，运行 `pnpm docs:check` 和 `pnpm docs:build`。有浏览器时预览图表、公式与交互，不能预览时明确说明；构建成功不能代替图表实际渲染检查。
