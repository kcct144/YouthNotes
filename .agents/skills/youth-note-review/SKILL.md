# 学科笔记审校

读取根目录 `AGENTS.md`、[笔记规范](../../../docs/guide/writing.md)和本次用户指定的页面或差异。纯审阅任务先给意见；用户要求修复时再直接修改。

按对学习的影响检查：定义与条件是否成立；推理是否跳步；例题条件是否充分、答案是否唯一；计算、符号与单位是否一致；反例是否真的反驳所述结论。独立解题，不能只因为解析通顺就认定正确。

对照正文检查图表的坐标、单位、取值范围、采样数据与文字结论；区分实测和模拟。核实实际引用过的来源，不把未经查证的课程或“必考”结论写成事实。分清错误、条件不明、待核对与可选改进。

检查知识点是否解释了为什么、考点是否说明方法与条件、坑点是否提供可操作的检查办法，不要求每页强制包含三类。

按[共建记录教程](../../../docs/guide/contributions.md)检查 `noteContributors` 和 `noteChanges`：保留真实内容贡献者，区分 `recordedBy` 代录人，不把 Git 提交者当作学生署名；确认移动、拆分与合并没有遗漏相关贡献。校验只能判断格式，真实姓名、贡献与日期缺乏依据时交由师生确认，不自行补造。

反馈提供文件位置、具体问题、影响和最小修改建议，优先报告影响理解或答案的问题。没有依据时说明不确定性，不凭空制造问题。网站检查通过与知识正确是两件事。

如改了内容，运行 `pnpm docs:check`、`pnpm docs:build` 并如实报告结果；不会因审阅任务自动提交、合并或发布。
