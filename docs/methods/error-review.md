# 错题复盘：把错误变成下一次的检查动作

**适用范围**：各学科；以下是可以尝试的操作示例，不保证对每个人同样有效。

## 从一次错误开始

先不抄整段答案，写出自己卡在哪里：概念没理解、条件漏看、方法选错，还是运算或表达出了问题。保留原来的关键一步，才能知道之后是否真的改进。

| 记录项 | 一次函数例子 |
| --- | --- |
| 我怎么想的 | 看到截距为正，就判断函数一定递增 |
| 错在哪里 | 把截距和斜率的作用混淆了 |
| 反例 | $y=-x+2$ 的截距为正，但随 $x$ 增大而减小 |
| 下次检查 | 判断增减先看 $x$ 的系数，再看自变量范围 |

## 不看解析，再做一道

合上解析，重新解释正确方法，然后找一道条件略有变化的题自行完成。隔一段时间再尝试一次；如果仍然出错，回到概念和条件，而不是只增加抄写次数。

## 把共性问题写回 Wiki

同一主题多次出现的错误可以提炼成“坑点”：错法、错因、反例、自查办法。个人试卷和分数留在自己的记录中，公共页面只保留可帮助大家理解的内容。
