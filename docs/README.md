## 一页笔记，三种视角

::: tip 知识点 · 理解为什么
讲清概念、成立条件和知识之间的联系，用自己的话解释，再用例子帮助理解。
:::

::: note 考点 · 学会怎么做
按题型归纳识别线索和解题方法，通过典型例题展示过程，而不只给出答案。
:::

::: warning 坑点 · 知道哪里容易错
记录容易忽略的条件、错误推理和反例，说明错因与检查方法。
:::
