# 共建指南

学生可以通过课堂讨论、纸笔材料或老师约定的方式贡献内容，由维护者整理与代录。会编辑 Markdown 的同学也可以直接参与。

| 你要做什么 | 阅读入口 |
| --- | --- |
| 第一次参与或运行项目 | [十分钟入门](./quickstart.md) |
| 写知识点、例题或易错提醒 | [一页笔记怎么写](./writing.md) |
| 写公式、化学式和图表 | [公式与图表](./math-and-charts.md) |
| 记录学生贡献、老师代录与修改历史 | [贡献者与修改记录](./contributions.md) |
| 和同学一起完善并接受审阅 | [协作与审校](./collaboration.md) |
| 让 AI 辅助写作与检查 | [使用项目 skills](./ai-skills.md) |
| 配置远程仓库与部署 | [维护指南](./maintenance.md) |

推荐从小修改开始：把一个容易误解的概念讲清楚，或者为已有坑点补一个反例。[一次函数示范](../notes/math/junior/linear-function.md)可以直接对照源文件学习。
