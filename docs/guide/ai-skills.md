# 使用项目 skills

Skill 是仓库中的任务说明，让 AI 按同一套笔记约定工作。文件位于 `.agents/skills/`，根目录 `AGENTS.md` 提供任务入口；它们会跟随仓库一起共享，不需要每位同学复制个人配置。

## 三个预设任务

| Skill 名称 | 适合什么时候用 | 会重点处理什么 |
| --- | --- | --- |
| `youth-note-write` | 新建或整理学科笔记 | 适用范围、讲解、例题、坑点、来源与真实贡献记录 |
| `youth-note-review` | 修改后审校或检查 PR | 概念条件、推导答案、来源与待核对问题 |
| `youth-science-visuals` | 添加公式、化学式或图表 | 已有语法、数据一致性、文字替代与预览 |

支持 skill 调用的工具可以按名称选择；也可以直接让 AI 读取对应路径的 `SKILL.md`。其他编辑器同样可以把该文件当作任务说明使用。

## 提问时给足真实材料

```text
请使用 $youth-note-write，完善 docs/notes/math/junior/linear-function.md。
对象：刚学一次函数的初中生。
目标：解释斜率和截距的区别，补一道原创例题。
资料：以当前页面和我提供的课堂讲义为依据。
不确定的结论列为待核对，不编造教材页码。
本次反例由课堂上的同学提出，我会另行提供其协作昵称；不要根据录入人或 Git 身份补署名。
```

审校时可以这样写：

```text
请使用 $youth-note-review 检查我刚修改的笔记。
先列影响理解或答案正确性的问题，指出位置与理由。
重新计算例题，检查成立条件；先给审阅意见，不替我提交或推送。
```

添加图表时可以这样写：

```text
请使用 $youth-science-visuals，为一次函数页面增加 y=-x+2 的图像。
范围是 -2≤x≤3；标清坐标轴，给出采样数据表，解释它与 y=2x+1 的区别。
```

## 学生负责最后的理解与核对

先自己尝试解释或解题，再让 AI 指出遗漏与跳步。不要用流畅的措辞代替证据，不直接采用虚构的考试频率、真题出处或实验数据。

修改后阅读差异，运行 `pnpm docs:check` 与 `pnpm docs:build`，实际预览页面。AI 可以协助改文件和检查，但提交、推送、合并、部署需按你当次明确的要求执行。
