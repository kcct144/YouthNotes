## 清单 · 常见离子的水溶液颜色

| 离子 | 常见颜色 |
| --- | --- |
| 铜离子 $\ce{Cu^2+}$ | 蓝色 |
| 铁离子 $\ce{Fe^3+}$ | 黄色至棕黄色 |
| 亚铁离子 $\ce{Fe^2+}$ | 浅绿色 |
| 高锰酸根离子 $\ce{MnO4^-}$ | 紫红色 |

这些颜色适用于课堂常见的水溶液。浓度和溶液组成会影响观察到的颜色，尤其是铁离子溶液的色调。参见英国皇家化学会的[无机物水溶液观察](https://edu.rsc.org/download?ac=532013)和[铁的氧化态实验](https://edu.rsc.org/experiments/oxidation-states-of-iron/517.article)（查阅于 2026-11-20）。

## 清单 · 水和钠元素的检验现象

| 检验对象 | 方法与现象 |
| --- | --- |
| 水 | 白色无水硫酸铜遇水变蓝。 |
| 钠元素 | 用焰色试验观察，火焰呈黄色。焰色试验可用于识别某些金属元素。 |

参见英国皇家化学会的[硫酸铜遇水变色实验](https://edu.rsc.org/experiments/a-reversible-reaction-of-hydrated-copperii-sulfate/437.article)和[焰色试验](https://edu.rsc.org/experiments/testing-salts-for-anions-and-cations/464.article)（查阅于 2026-11-20）。

## 考点 · 检验氯离子

先用**稀硝酸**酸化待测溶液，再加入硝酸银溶液。在排除其他干扰离子的条件下，生成白色氯化银沉淀可作为检出氯离子的依据。

$$
\ce{Ag+(aq) + Cl-(aq) -> AgCl(s)}
$$

参见[英国皇家化学会的阴离子检验实验](https://edu.rsc.org/experiments/testing-for-negative-ions/758.article)（查阅于 2026-11-20）。

### 坑点 · 碳酸根也能与银离子生成沉淀

直接加入硝酸银溶液时，碳酸根也可能生成碳酸银沉淀。碳酸银的化学式是 $\ce{Ag2CO3}$，一个 $\ce{CO3^2-}$ 需要两个 $\ce{Ag+}$ 才能使总电荷为零。先加稀硝酸，可使碳酸根转化为二氧化碳和水。若改用盐酸酸化，盐酸本身会引入氯离子。
