## 知识点 · 氯气、液氯与氯离子

氯气和液氯是同一种单质 $\ce{Cl2}$ 的两种状态。氯离子 $\ce{Cl-}$ 是氯原子得到一个电子后形成的离子。在钠和氯气的反应中，钠失去电子，氯气得到电子生成氯离子。单质中的氯为 $0$ 价，氯离子中的氯为 $-1$ 价，两者的化学性质不同。

## 清单 · 氯气与金属反应的现象和产物

| 反应对象 | 课堂典型现象或产物 |
| --- | --- |
| 钠 | 燃烧时有黄色火焰，生成的氯化钠固体小颗粒形成白烟。 |
| 铁 | 铁在氯气中燃烧，产物为氯化铁 $\ce{FeCl3}$。 |

表中指金属直接在氯气中燃烧。参见普渡大学的[钠与氯气反应演示](https://chemed.chem.purdue.edu/demos/demosheets/7.1.html)和威斯康星大学麦迪逊分校的[铁与氯气反应演示](https://demolab.chem.wisc.edu/types-of-chemical-reactions-reaction-of-chlorine-with-iron/)（查阅于 2026-11-20）。

## 知识点 · 次氯酸的漂白性

氯气溶于水后，一部分与水反应生成盐酸和次氯酸 $\ce{HClO}$。氯水使紫色石蕊溶液先变红再褪色。变红来自溶液的酸性，褪色来自次氯酸的氧化作用。用试纸观察这一现象时，试纸要湿润，才能为氯气与水的反应提供条件。

次氯酸见光容易分解。

$$
\ce{2HClO(aq) ->[\text{光照}] 2HCl(aq) + O2(g)}
$$

### 清单 · 常见含氯漂白物质

| 对象 | 含氯成分 |
| --- | --- |
| 氯水 | 次氯酸 $\ce{HClO}$ 起漂白作用。 |
| 常见含氯漂白液 | 有效成分通常是次氯酸钠 $\ce{NaClO}$。 |
| 漂白粉 | 有效成分是次氯酸钙 $\ce{Ca(ClO)2}$。 |

次氯酸钠和次氯酸钙都属于次氯酸盐，在水中可形成次氯酸。参见[美国疾控中心的化学消毒剂说明](https://www.cdc.gov/infection-control/hcp/disinfection-sterilization/chemical-disinfectants.html)和[俄勒冈州立大学国家农药信息中心的说明](https://npic.orst.edu/factsheets/pool-chemicals.html)（查阅于 2026-11-20）。

## 考点 · 区分洗气、干燥和尾气处理

| 环节 | 作用与判断依据 |
| --- | --- |
| 洗气 | 目标是除去混在氯气中的氯化氢。 |
| 干燥 | 目标是除去水蒸气。选干燥剂时，要考虑它是否会与氯气反应。 |
| 尾气处理 | 目标是吸收剩余氯气。氢氧化钠溶液能与氯气反应。澄清石灰水中溶解的氢氧化钙较少，吸收能力有限。 |

### 坑点 · 有固体剩余，反应也可能停止

在以盐酸为反应物的课堂制气演示中，盐酸会随反应进行而变稀。浓度太低时，即使还有固体剩余，产气也可能停止。加热还会影响氯化氢的挥发，观察到的气体可能含有杂质。
