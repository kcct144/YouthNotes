# 一次函数：从变化关系到图像

**适用范围**：初中一次函数入门，不绑定教材版本。

**先修知识**：代数式、方程、平面直角坐标系。

**学习目标**：解释斜率与截距的意义，用两个点确定一次函数，并检查自变量范围。

## 【知识点】什么在变，怎样变

::: tip 知识点 · 定义与条件
形如 $y=kx+b$，其中 $k,b$ 为常数且 $k\ne 0$ 的函数，叫作一次函数。$x$ 的取值范围还要结合题目或实际情境确定。
:::

对同一个函数，自变量变化 $\Delta x$，函数值就变化 $k\Delta x$：

$$
\Delta y = k\Delta x, \qquad k=\frac{y_2-y_1}{x_2-x_1}\quad(x_1\ne x_2).
$$

在允许的取值范围内，$k>0$ 时，$x$ 增大，$y$ 也增大；$k<0$ 时，$x$ 增大，$y$ 减小。$b$ 是直线 $y=kx+b$ 与 $y$ 轴交点的纵坐标；若情境不允许 $x=0$，该交点可能不属于情境对应的图像。

## 【考点】由两个点确定表达式

::: note 考点 · 待定系数法
已知一次函数图像经过横坐标不同的两个点，可以把坐标分别代入 $y=kx+b$，解出 $k,b$，再代回原条件检验。
:::

### 例题（原创）

已知一次函数图像经过 $A(1,3)$、$B(3,7)$，求表达式，并求 $x=5$ 时的函数值。

<details>
<summary>先自己尝试，再展开思路与解析</summary>

两个点提供两个条件。设 $y=kx+b$，代入得到：

$$
\begin{cases}
k+b=3,\\
3k+b=7.
\end{cases}
$$

两式相减，得到 $2k=4$，所以 $k=2$；再代入得 $b=1$。

因此表达式为 $y=2x+1$。当 $x=5$ 时，$y=11$。

检验：$2\times1+1=3$、$2\times3+1=7$，且 $k\ne0$，满足题目条件。

</details>

```mermaid
  A[读出两个点的坐标] --> B[代入表达式列方程]
  B --> C[求出 k 和 b]
  C --> D[代回两个点并检查条件]
```

## 【坑点】不要把不同条件混在一起

::: warning 坑点 · 忘了检查 k 是否为零
$y=3$ 可以写成 $y=0x+3$，但因为 $k=0$，它是常函数，不是这里定义的一次函数。检查表达式形式时要连同条件一起看。
:::

::: warning 坑点 · 用截距判断增减
$b>0$ 不能说明函数递增。反例是 $y=-x+2$：虽然 $b=2>0$，但 $k=-1<0$，函数随 $x$ 增大而减小。判断增减先检查 $k$ 的符号。
:::

::: warning 坑点 · 忽略实际取值范围
某活动费用按 $y=2x+1$ 元计算，$x$ 表示参与人数时，$x$ 只能取题目允许的非负整数或正整数，不能直接把整条直线当作实际情境的图像。画图或求值前先说明范围。
:::
