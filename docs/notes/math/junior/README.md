数学的阅读顺序从数与式出发，经过方程与不等式、函数，再进入图形的性质与变化，最后讨论统计与概率。计算规则要与成立条件一起理解，图形问题要把结论与依据对应起来。

每页先读知识点，明确概念、依据和条件；再按考点归纳的方法尝试例题，展开答案核对推理；最后用坑点检查容易混淆的边界。
